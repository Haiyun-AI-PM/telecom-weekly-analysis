# 电信经营周报分析 · 教学样例交付

在 CogSeed 中完成的一次端到端练习：**先做一周经营分析 → 首次核验 → 沉淀为可复用个人 Skill → 换一周数据复用 → 审核修正并保留过程**。全部为 AI 协作产出的教学样例，数据是人工编写的 `week-a.json` / `week-b.json`，**不是任何运营商真实客户数据**，不含落地效果声明。

## 交付三块内容

**1. 业务报告（5 份，均含完整核算与来源标注）**

| 文件 | 内容 |
| --- | --- |
| `outputs/01_经营周分析.md` | 第一周（10-12~10-18）首版分析 |
| `outputs/02_经营周分析_核验版.md` | 第一周核验版：补逐级分解、绝对/相对口径、事实与假设分离 |
| `outputs/03_第二周经营分析.md` | 第二周（10-19~10-25）**Skill 复用首版原稿，保留不动** |
| `outputs/04_第二周经营分析_核验简版.md` | 第二周**审核修正版**：正文约 600 字＋附录 |
| `outputs/05_第一周周会简版.md` | 第一周周会一页纸，正文约 600 字＋附录；动作均为计划（执行日自 2026-10-26 起），未倒填结果 |

**2. 个人 Skill（逐字导出，未改写）**
`skill/telecom-weekly-analysis/` — `SKILL.md` ＋ `references/`（8 份）＋ `evals/evals.json`，排除安装元数据 `_meta.json`。SHA256 逐字节校验：**10/10 一致，缺失 0，多余 0**。复算：`python3 scripts/verify_skill_export.py <本机已安装Skill目录>`。

**3. 第二周复用证据**
`evidence/01_首次核验.md`（第一周核验记录）、`evidence/02_Skill导出与复用记录.md`（导出方式、SHA256 表、真实复用情况、审核发现、限制）、`evidence/02_skill_export_sha256.txt`（校验结果，已隐去本机路径）。

## 第二周的核心结论（复用结果）

线索 200→240（+20.00%），办理 16→24（+50.00%），但**触达率 80.00%→60.00%（-20.00 个百分点，相对 -25.00%）**。新增线索增加、触达率下降：若维持 80.00% 触达率，240 条线索应有 192 个有效沟通，实际 144，账面结构差 48 个——**是账面差额，不等于已查明流失**。整体办理率仅 8.00%→10.00%（+2.00 个百分点）。

## 审核修正了什么（首版 → 修正版）

1. 「后两级都以触达率为分母」不准确：预约率分母是有效沟通，办理率分母是预约，只有预约率以触达结果为分母。
2. 费用解释卡不是「六项」，业务规范要求的是 **5 组字段**：月费、一次性费用、优惠生效条件与期限、到期变化、退订/变更条件。
3. 补触达缺边界：**跨周补触达必须单建原队列跟进台账**，不得混入次周新线索的同周漏斗，也不得用次周新线索触达率验收旧队列；04 中每条建议均标明验收队列。

## 边界（请勿放大解读）

- 仅 1 次跨周复用、单一数据形状；多产品/多网格/分渠道、含生命周期口径、真实资费金额等场景**未验证**。
- Skill 自带的 `evals/evals.json` 用例为空，`references/` 部分契约仍为占位模板；本次**未做自动化回归**。
- 未提交教师评审、课程评分或平台评审，**不主张已通过教师评价**；Skill 治理声明为 `promotion_ceiling: staged`、`production_release_allowed: false`，**不主张可生产上线**。
- 按业务规范：只用汇总数据，不采集客户身份信息、不实际联系客户、不实施营销或人员调度；不编造资费、赠品或收益承诺。
- GitHub 保存成果及版本历史；EduSeed 的接收与评价状态单独记录，不以网页成功提示替代正式提交记录。

## 下次怎么直接用

在 CogSeed 的技能列表找到 `telecom-weekly-analysis`，点击“使用此技能”，选工作空间并提供新周报、指标口径与业务资料。例如：

> 用这个 Skill 分析 samples/week-b.json，业务依据用 materials/业务说明与办理规范.md，计划执行日起2026-10-26，结果保存到指定文件。

另一台电脑可通过其 Skill 创建/导入流程加载 `SKILL.md`；不要手改安装目录。跨机导入尚未实测。

## 这份作业的价值

学员交出两类成果：**这一周能读懂、能复核的业务报告，以及下一周可以再次调用的分析方法。** 教师可以从首稿、纠错、Skill源码和复用结果判断学员是否掌握方法；一次实训结束后，方法仍可继续使用。
